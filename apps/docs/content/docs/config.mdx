The Convect configuration file is a JavaScript file that exports a configuration object. This object contains various settings and options that control the behavior of Convect.

<Callout>
  Run `npx convect-xyz init` in your project root directory to create a configuration file in your project.
</Callout>


## Configuration File

```js
// convect.config.mjs
export default {
  // ...config options
};
```

## Configuration Options
The configuration object can contain the following options:
