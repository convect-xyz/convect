  <Step>
    ### Create a Convect Function

    In the preferred project, <Link href={`${env.NEXT_PUBLIC_APP_URL}/projects`}>create a new Convect Function</Link>.

  </Step>
  <Step>
    ### Initialise Convect

    Initialise Convect in your project directory.


    ```bash title="terminal"
    npx convect-xyz init
    ```

  </Step>
  <Step>
    ### Write your handler
    The `transaction` API is used to define a handler for transactions that contain any of the specified logs. When your Convect Function runs, it receives these transactions in batches (max 60 transactions per batch).

    For the example below, the `transfer` handler will be called for all transactions that contain a `Transfer` log originating from the USDC contract.

    You can read the [API reference](/docs/api-reference) for detailed information on what you can do with the `transaction` API.

    ```ts title="src/convect/handlers/transfer.ts"
    import { tokenABI, tokenAddress } from './abis/token'
    import { log, transaction } from "convect-xyz";

    const usdc = '0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48';

    export const transfer = transaction({
      logs: [
        log({
          origin: usdc,
          signature: "event Transfer(address from, address to, uint256 value)"
        })
      ],
      handler: async (transactions) => {
        // Implement your transaction handler here. eg.
        await prisma.activity.createMany({
          data: transactions.flatMap(tx => tx.logs).map((log) => ({
            from: log.args.from // Inferred as `0x${string}`,
            to: log.args.to // Inferred as `0x${string}`,
            tokenId: log.args.tokenId // Inferred as bigint
          }))
        })
      }
    });
    ```

    <Callout title="Convention">For better readability, define related handlers in a separate file as shown above.</Callout>

  </Step>
  <Step>
    ### Export a Convect Function

    The `convect` API is used to export a Convect Function. This ties all your handlers together. Handlers run in the order they are specified in the `handlers` array.

    ```ts title="src/convect/[project-name]/[function-name].convect.ts"
    import { transfer } from "./transfer";
    import { convect, ethMainnet } from "convect-xyz";

    export default convect({
      chains: [ethMainnet],
      handlers: [transfer]
    });
    ```

    <Callout title="Good to know">When your Convect Function receives batches of transactions, it will call all matching transaction handlers in the order they are specified in the `handlers` array.</Callout>

  </Step>
  <Step>
    ### Authenticate & Deploy

    Authenticate with the command below.
    ```bash title="terminal"
    npx convect-xyz auth
    ```

    Create a new deployment with the command below.
    ```bash title="terminal"
    npx convect-xyz deploy -s [project]/[function]
    ```

    The new deployment should be available in the <Link href={`${env.NEXT_PUBLIC_APP_URL}/projects`}>Projects</Link> page.

  </Step>
</Steps>
