  <Step>
    ### Export a convect function

    All transaction handlers included in a `convect` function will be processed in order.

    ```ts title="src/convect/ingest.ts"
    import { transfer } from "./transfer";
    import { convect } from "@convect-xyz/sdk";

    export default convect({
      transfer
    });
    ```
  </Step>

    ### Upload a new deployment

    ```bash title="terminal"
    export CONVECT_API_KEY="<Your API Key>"
    npx @convect-xyz/cli init
    ```
